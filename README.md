# rsschool-cv

## Транспортная карта Барановичей (демо)

Интерактивная карта маршрутов Автобусного парка г. Барановичи:
тёмный premium-интерфейс, glassmorphism, живые маркеры транспорта,
карточки остановок, изменения движения, избранное и подписки.

- Страница: [`map/index.html`](map/index.html)
- Документация и архитектура: [`map/README.md`](map/README.md)

Запуск локально:

```bash
cd map && python3 -m http.server 8080
# http://localhost:8080
```

> Отображаются демонстрационные данные (бейдж «Демо-данные») —
> реальный GPS-провайдер пока не подключён.
