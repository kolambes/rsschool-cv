Редактор расписания

Выберите маршрут, направление и остановку. Ниже можно исправить время или добавить новое.

Обновление расписания из XML

Загрузите актуальные XML-файлы маршрутов. Можно обновить только выбранные маршруты или полностью пересобрать расписание в базе.

Отложенная замена

Если дата в будущем, старое расписание останется активным до этого времени, а новый XML применится автоматически.

Запланированные замены Маршрут можно отменить до даты запуска. После применения остается резервная копия для отката.
Откат расписания Перед каждой XML-загрузкой сохраняется копия.

Журнал изменений

Последние правки расписания, названий маршрутов и остановок.

Карта

Геоданные для карты Mini App: координаты остановок, линии маршрутов, изменения движения и демо-режим транспорта.

Демо-данные

Схематичные геоданные для проверки карты, пока не заполнены реальные координаты. Все демо-записи помечены и удаляются одной кнопкой; на карте пользователи видят бейдж «Схема (демо-геоданные)».

Редактор геоданных

Выберите остановку слева, затем кликните по карте, чтобы задать её координаты.

Геометрия маршрута

Изменения движения

Публикация отправит уведомление всем подписчикам маршрута в Telegram и покажет изменение на карте.

Разнарядка водителей

Загрузите CSV-файл. Система сама сопоставит табельные номера с Telegram ID и отправит водителям личные уведомления.

Водители берутся из вкладки «Работники»

Добавьте сотрудника с ролью «Водитель», укажите табельный номер и отряд. После этого он автоматически появится здесь и будет участвовать в CSV-рассылке.

CSV разнарядки

После загрузки CSV рассылка запускается автоматически. Служебные строки, номера выездов и технические поля водителям не отправляются.

Журнал разнарядок

Последние загрузки, отчеты отправки и водители без регистрации.

Работники

Добавьте Telegram ID работника и выберите роль. Роль “Работник” нужна только для служебных пуш-уведомлений.

Работник должен хотя бы один раз открыть бота, чтобы Telegram ID принимал сообщения.
