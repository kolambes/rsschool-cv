Аудит BarBus Mini App от 06.06.2026

Проверены публичное Mini App, админ-панель, серверные API, импорт XML, обращения, новости, избранное, услуги, роли сотрудников, базовая нагрузка и smoke-сценарии.

Исправлено

Безопасность

  • Убран слабый ADMIN_KEY по умолчанию и добавлена защита от слабого ключа.
  • Подмена роли через x-admin-role отключена без явного ALLOW_ADMIN_ROLE_OVERRIDE=true.
  • Опасные очистки ограничены полным администратором.
  • Вложения в чат обращений сохраняются только после проверки доступа.
  • Токен клиентского чата больше не передаётся через URL.
  • Добавлены лимиты на лайки, просмотры новостей и XML-импорт.

Расписание и XML

  • Публичный кэш очищается после импорта XML, ручных правок и отката.
  • Полная замена XML требует тип расписания и не удаляет другие типы транспорта.
  • CLI-импорт рекурсивно читает XML и требует тип расписания.
  • Время и маски дней в XML валидируются строже.
  • Зависшие отложенные XML-замены возвращаются в очередь.

UX и админка

  • Тема Telegram больше не перетирается при первом запуске.
  • Новости не помечаются все просмотренными при открытии вкладки.
  • Избранное сохраняет раскрытый будильник после обновления.
  • Удаление времени больше не удаляет весь рейс случайно.
  • Форма сотрудников очищена от лишней роли, Telegram ID валидируется.

Проверки

  • node --check для ключевых JS-файлов.
  • npm run verify
  • npm run test:ux
  • npm run test:smoke
  • npm run test:load: 240 запросов, 24 параллельных клиента, 0 ошибок.
