# Инструкция для передачи проекта

Проект: Telegram-бот, Telegram Mini App, админ-панель и SQLite-база для расписания и обращений автобусного парка.

Этот файл предназначен для людей, которым передают архив проекта. В передаточном архиве нет локального `.env`, логов, временных файлов и приватных вложений обращений. Если в архив добавлена `data/app.db`, это очищенная копия базы: расписание и публичные справочники сохранены, а обращения, подписчики, сотрудники, визиты, разнарядки и приватные файлы удалены.

## Что нужно для запуска

- Node.js 24 или новее. Это важно, потому что проект использует встроенный модуль `node:sqlite`.
- Публичный HTTPS-адрес, если Mini App и бот должны работать в Telegram.
- Токен Telegram-бота от `@BotFather`.
- Доступ к серверу или компьютеру, где будет постоянно запущен Node.js-процесс.

В проекте нет внешних npm-зависимостей. `npm install` можно выполнить для привычного сценария, но скачивать пакеты проекту сейчас не требуется.

## Быстрый локальный запуск

```bash
cd bar-bus
npm run dev:local
```

Открыть в браузере:

- Mini App: http://localhost:3000
- Админ-панель: http://localhost:3000/admin
- Проверка здоровья: http://localhost:3000/api/health

`dev:local` отключает Telegram polling и удобен для просмотра интерфейса без реального бота.

## Запуск через `.env`

1. Скопируйте пример настроек:

   Windows:

   ```powershell
   copy .env.example .env
   ```

   Linux/macOS:

   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и заполните свои значения:

   ```bash
   PORT=3000
   NODE_ENV=production
   CITY_NAME=Барановичи
   WEBAPP_URL=https://your-domain.example
   BOT_TOKEN=123456:telegram-token
   ADMIN_KEY=replace-with-long-random-secret
   FILE_ACCESS_SECRET=replace-with-another-long-random-secret
   ADMIN_IDS=123456789,987654321
   ADMIN_CHAT_ID=-1001234567890
   REQUIRE_TELEGRAM_AUTH=true
   DISABLE_TELEGRAM_POLLING=false
   ```

3. Запустите:

   ```bash
   npm start
   ```

4. Откройте адрес из `PORT`, например:

   - http://localhost:3000
   - http://localhost:3000/admin
   - http://localhost:3000/api/health

Важно: если оставить `PORT=3066` из `.env.example`, адрес будет `http://localhost:3066`.

## Настройка Telegram

1. Создайте бота через `@BotFather` и получите `BOT_TOKEN`.
2. Укажите публичный HTTPS-адрес приложения в `WEBAPP_URL`.
3. В `@BotFather` настройте Mini App/Menu Button на тот же HTTPS-адрес.
4. В `.env` укажите `ADMIN_IDS`: Telegram ID администраторов через запятую.
5. Укажите `ADMIN_CHAT_ID`, если нужно отправлять служебные уведомления в отдельный чат или группу.
6. Запустите приложение с `DISABLE_TELEGRAM_POLLING=false`.

При старте сервер сам настраивает команды бота и кнопку меню Telegram. Если бот ранее работал через webhook, приложение по умолчанию очищает webhook перед polling.

## Данные и расписания

Если в архиве есть `data/app.db`, приложение уже должно открываться с расписанием и публичными данными.

Если нужно импортировать расписание заново, используйте XML-файлы и обязательно передавайте тип расписания:

```bash
npm run import:routes -- "C:\path\to\city-xml" city
npm run import:routes -- ".\tmp_transport_zips_20260602\suburban" suburban
npm run import:routes -- ".\tmp_transport_zips_20260602\intercity" intercity
```

Типы: `city`, `suburban`, `intercity`.

В архиве может быть папка `tmp_transport_zips_20260602` с пригородными и междугородними XML. Городские XML-файлы, если их нет в архиве, нужно передать отдельно или пользоваться уже подготовленной базой `data/app.db`.

## Что умеет приложение

- Показывает расписание автобусов по маршрутам, направлениям и остановкам.
- Поддерживает городские, пригородные и междугородние маршруты.
- Имеет поиск по маршрутам и остановкам.
- Показывает табло остановки и ближайшие отправления.
- Позволяет сохранять избранные остановки и рейсы.
- Ставит напоминания о рейсе за 5, 10, 15, 20 или 30 минут.
- Отправляет напоминания через Telegram-бота.
- Показывает новости, рекламу, услуги, контакты и руководство.
- Принимает обращения пассажиров из Mini App.
- Поддерживает вложения к обращениям: изображения и аудио.
- Ведет чат по каждому обращению между клиентом и администрацией.
- Имеет адаптивный интерфейс для телефона и браузера.

## Что умеет админ-панель

- Просмотр сводки и статистики посещений.
- Работа с обращениями: список, статусы, чат, ответы клиентам.
- Разделение доступа по ролям: `admin`, `appeals_manager`, `ads_manager`, `dispatcher`, `moderator`, `sto_manager`, `driver`.
- Управление расписанием: импорт XML, ручные правки отправлений, аудит, резервные копии, откат, отложенные импорты.
- Управление рекламой, новостями, услугами и контактами руководства.
- Создание и отправка push-уведомлений через Telegram.
- Управление сотрудниками и их ролями.
- Разнарядка водителей: загрузка CSV, проверка табельных номеров, отправка заданий водителям в Telegram.
- Автоматическая ежедневная отправка разнарядки, если включена и есть подготовленный CSV.

## Что умеет Telegram-бот

- `/start` - показывает приветствие и кнопку открытия Mini App.
- `/help` - показывает краткую справку.
- `/routes` - сообщает количество доступных маршрутов и предлагает открыть Mini App.
- `/appeal` - запускает создание обращения.
- `/appeals` - открывает список обращений пользователя или рабочие обращения сотрудника.
- `/work` - показывает сотруднику открытые рабочие обращения по его роли.
- `/admin` - запускает проверку доступа администратора.
- `/clear` - очищает текущее действие в чате.
- `/done` - закрывает активный рабочий чат обращения для сотрудника.

Пассажир через бота может:

- создать обращение по теме: жалоба, расписание/остановка, реклама, СТО/услуги, другая проблема;
- отправлять текст, фото и аудио к обращению;
- смотреть свои обращения и продолжать переписку;
- получать ответы администрации прямо в Telegram;
- получать напоминания о выбранных рейсах;
- получать push-уведомления, если он уже взаимодействовал с ботом или Mini App.

Сотрудник через бота может:

- получать уведомления о новых обращениях;
- открыть обращение кнопкой из уведомления;
- отвечать клиенту из личного чата с ботом;
- закрывать обращение;
- открыть админ-панель через кнопку Telegram;
- отправить XML расписания или CSV разнарядки боту как документ, а затем забрать файл во вкладке админ-панели.

Водитель через бота может:

- быть привязан по Telegram ID и табельному номеру;
- получать разнарядку из загруженного CSV;
- получать сообщение, если на выбранную дату назначения нет.

## Проверка после запуска

```bash
npm run verify
```

Проверка поднимает сервер на свободном порту и проверяет главную страницу, админку, API, маршруты и расписание.

Дополнительные проверки:

```bash
npm run test:smoke
npm run test:load
```

## Что не передавать публично

- `.env` с настоящим `BOT_TOKEN`, `ADMIN_KEY`, `FILE_ACCESS_SECRET`.
- Рабочую `data/app.db`, если в ней есть реальные обращения, подписчики, сотрудники или история посещений.
- `data/uploads/` и `public/uploads/appeals/`, если там есть пользовательские вложения.
- Логи `*.log`.
- Временные папки `tmp-*`.

Если нужен полный перенос рабочей системы между доверенными администраторами, передавайте настоящую базу и приватные загрузки отдельным защищенным способом, а после передачи смените `ADMIN_KEY` и другие секреты.
